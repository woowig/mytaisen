# ゲーム仕様

英傑大戦風の1対1対戦ゲームのルールです。数値はすべて仮の値です。

- 数値の正は [`src/shared/constants.ts`](../src/shared/constants.ts) です。
- ロジックの正は [`src/shared/game.ts`](../src/shared/game.ts) です。

## 1. 画面と操作

画面は2つのフィールドを左右に並べます。

| フィールド | 役割 |
|---|---|
| カードフィールド(左) | 自分のカードをドラッグして、部隊の目的地を指示する盤。自分のカードしか出ません |
| バトルフィールド(右) | サーバーが計算した戦場。部隊は指示位置へ、遅れて歩いて向かいます |

- 自城は常に画面の**下側**、敵城は**上側**です。後攻(プレイヤー2)の表示は上下左右を反転します。
- 両フィールドとも、**敵城エリアを除いた範囲**(幅600×高さ890)を同じ大きさで表示します。敵城の中は見えません。
- 上端中央に、敵の城門の位置を示すマーカー(カード1枚分の幅)が出ます。

| 操作 | 内容 |
|---|---|
| カードをドラッグ | 部隊の目的地を指示。城の外へ出すと出城、自城エリアへ戻すと帰城 |
| 空き地をクリック | 選択中のカードの目的地をそこにする |
| `1`〜`8` | カードの選択 |
| `Q` | 選択中のカードの計略 |
| カードをダブルクリック | そのカードの兵種アクション(斬撃・射撃) |
| カードを振る | 剣豪の斬撃(短い距離を素早く往復させる) |
| カードを前後に揺らす | 鉄砲隊の射撃(縦に短く素早く往復させる) |

ダブルクリックは、同じカードを約300ミリ秒以内に、ほとんど動かさずに2回クリックしたときだけ成立します。ダブルクリックしたカードを選択して、そのカードの兵種アクションを発動します。1回のクリック、ドラッグ、空き地のダブルクリックでは発動しません。固有アクションを持たない兵種(槍兵の槍撃は自動発動)や、アクションを使えない状態のカードでは何も起きません。

カードの上端が敵の城壁に接する位置(余裕あり)に置くと、部隊を城壁まで進める指示になります。

## 2. 用語とフィールド

- フィールドは論理座標で **幅600×高さ1000** です。
- プレイヤー1(先に部屋に入った側)の自城は下端、プレイヤー2の自城は上端です。
- **城エリア**は、各自陣の端の高さ110の範囲です。
- **城壁**は、城エリアの境界の線です。
- **城門**は、城の中央にある幅44(半幅22、カード1枚分)の入口です。

## 3. デッキ

サーバーが入室時に検証します。

| 条件 | 値 |
|---|---|
| 総コスト | 9以内 |
| 枚数 | 1〜8枚 |
| 同名武将 | 入れられない |
| 存在しないカード・重複 | 不可 |

### 最大士気

勢力(色)の数で決まります。

| 色の数 | 1 | 2 | 3 | 4以上 |
|---|---|---|---|---|
| 最大士気 | 12 | 10 | 8 | 6 |

- 特技「同盟」を持つ武将がいると、そのコストの分だけ最大士気が増えます(上限15)。
- 特技「昂揚」を持つ武将がいると、そのコストの分だけ開戦時の士気が増えます(基本は5)。
- 士気は毎秒0.3ずつ回復します。**消費するのは計略・短計の使用時だけ**です。

## 4. 試合の流れと勝敗

1. 開戦時、デッキの全カードが自城エリアにいます(`城内`)。
2. カードを城の外へ動かすと出城し、戦場を歩きます。
3. 制限時間は **99カウント**(1カウント=2.4秒、約237.6秒)です。

勝敗は次のとおりです。

| 条件 | 結果 |
|---|---|
| 敵城のゲージが0になった | その側の勝ち |
| 両軍の城が同時に0になった | 引き分け |
| 時間切れ | 城ゲージが多い方の勝ち。同じなら引き分け |
| 相手の切断 | 切断されなかった側の勝ち |

城ゲージの初期値は両軍100です。

### 部隊の状態

| 状態 | 内容 |
|---|---|
| 城内(castle) | 自城エリア内。兵力が毎秒、最大の8%ずつ回復。敵からは見えない |
| 出城(field) | 戦場にいる |
| 撤退(dead) | 兵力が0になった。一定時間後に自城で復活 |

- 兵力は**コストによらず一定**(100)です。特技「兵」で最大値が増えます(同時代の「兵」持ちのコスト合計×6%)。
- 復活までの時間は、8秒+3秒×コストです。特技「活」で0.6倍になります。復活すると、計略が再び使えます。

## 5. 敵城エリアの扱い

- 部隊は**敵城エリアには入れません**。城壁で止まります。
- 敵城エリア内にいる敵部隊(出入り中を含む)は、**相手に送られません**(サーバーが情報を出さない)。
- 自城エリア内にいる自分の部隊は、自分の画面では見えます。

## 6. 攻城

敵の城壁(城エリアの境界から28以内)に接した部隊が、攻城します。乱戦中の部隊はできません。

### 攻城ゲージ

- 攻城中は、部隊ごとにゲージが貯まります。満了すると、敵城にダメージを与えます。
- 満了までの秒数は、知力が高いほど短くなります(6.5秒−知力×0.35秒。1.6〜6.5秒)。
- 攻城中は、突撃・伏兵・隠密などの状態が解除されます。

### ダメージ

```
ダメージ = max(0.3, コスト×0.45 + 武力×0.16 + 兵種ボーナス) × 門倍率
```

| 兵種 | 槍兵 | 剣豪 | 騎兵 | 弓兵 | 鉄砲隊 |
|---|---|---|---|---|---|
| 兵種ボーナス | +0.5 | +0.35 | 0 | −0.2 | −0.2 |

### 城壁と城門

| 攻撃先 | 同時に攻撃できる部隊 | 倍率 |
|---|---|---|
| 城壁 | 何部隊でも | ×1 |
| 城門 | **1部隊だけ** | ×3 |

- 城門は、城の中央で、幅がカード1枚分です。壁際にいて、その幅に収まる部隊のうち、中央に近い1部隊が城門の担当になります。
- 担当は、範囲を外れるか乱戦になるまで続投します。外れたら、中央に近い部隊に交代します。
- 門の範囲にいる他の部隊は、城壁への攻撃(×1)になります。
- 弓・鉄砲で攻城中の部隊を撃つと、その部隊の攻城ゲージが減ります。

## 7. 兵種とアクション

兵種の相性は、**ダメージの倍率ではなく、アクション同士の関係**で表します。

| 兵種 | 基本速度 | 固有アクション |
|---|---|---|
| 騎兵 | 52 | なし(突撃は自動) |
| 槍兵 | 40 | なし(槍撃は移動中に自動発動) |
| 弓兵 | 38 | なし(自動で射撃) |
| 鉄砲隊 | 38 | 射撃 |
| 剣豪 | 45 | 斬撃 |

剣豪の斬撃はカードを振る操作、鉄砲隊の射撃はカードを前後に揺らす操作で、どちらもカードのダブルクリックでも発動できます。槍兵の槍撃は、操作なしで移動中に自動で発動します。

### 騎兵: 加速と突撃

1. 移動を始めると、**初速**(基本速度の20%)から、**加速度**(毎秒10)で徐々に速くなります。
2. 速度が**突撃発動速度**(基本速度の85%)に達すると、**突撃可能状態**になり、突撃オーラが表示されます。移動開始直後には突撃できません(初期値では約3.4秒)。
   - 突撃オーラは、進行方向に尖り、後方へ尾を引く橙色の炎の形です(先端寄りが明るく、尾の先ほど透明)。縁は短い周期で揺らぎ、後方へ流れる数本の速度線が付きます。向きは部隊の進行方向に合わせます。
   - 突撃可能状態で走ると、通った跡に足元から砂煙が舞い上がります。砂煙は発生した場所に残り、広がりながら薄くなって、0.6〜1秒で消えます。突撃可能状態になった瞬間には、周囲に一度だけ砂煙が広がります。突撃可能状態が解除されると、新しい砂煙は出ません。
   - オーラと砂煙は、部隊やカードの下に描かれます。砂煙の粒の数には上限があります。
3. 突撃可能状態では、移動速度が1.35倍になり、弓・鉄砲のダメージが半分になります。
4. 突撃可能状態の騎兵が敵部隊に接触すると、**突撃**が発生します(ダメージ=22+武力×2.2)。
5. 次の場合は、速度を失い、突撃可能状態が解除されます。
   - 止まる・目的地に着く
   - 柵に阻まれる
   - 進行方向が大きく変わる(前回との向きの余弦が0.9未満)
   - 乱戦になる、突撃の接触後
   - 速度が基本速度の60%を下回る
6. 槍兵の槍に向かい合って当たると、迎撃されます(後述)。剣豪の斬撃を受けると解除され、減速します。

### 槍兵

槍は、**移動方向に向かって常に出ています**。槍が出ていない(乱戦中・攻城中)ときは、槍撃も迎撃も起きません。

**槍の表示**
- バトルフィールドでは、槍は移動方向へ扇形に並ぶ4本の矢印で描かれます。外側の2本は槍撃の有効角度のすぐ内側に置かれ、槍撃が当たる範囲の目安になります。
- 移動している間は、4本が少しずつタイミングをずらして前後に伸び縮みし、突き出した瞬間に矢じりの先に小さな光が出ます。止まっている間は静止します。
- 槍の長さ(槍撃の範囲)は、止まっていても槍撃の発動中でも変わりません。槍撃の発動中は、移動中と同じ突き出しの表示になります。

**槍撃**
- 範囲は、槍兵の前方の短い距離(70。特技「槍術」で+8×コスト)と、移動方向から約37度以内の角度です。範囲外の敵には当たりません。
- 範囲内の敵すべてに、持続ダメージを与えます(武力×0.5/秒)。
- 騎兵に当たると、突撃可能状態が解除され、速度が**槍兵と同等まで**落ちます(1.5秒間、その速度が上限)。

**迎撃**
- 次の3つをすべて満たした敵に発動します(騎兵に限りません)。
  1. 槍撃の範囲内にいる。
  2. 移動速度が、騎兵の突撃発動速度(騎兵の基本速度の85%)以上。
  3. 槍の向きと相手の進行方向が向かい合っている(60度以内)。
- 大ダメージ(30+武力×1.5)と、4秒間の減速(半分)を与えます。クールダウンは2秒です。

**槍撃(自動発動)**
- 槍兵が移動している間、クールダウンが明けるたびに自動で発動します。操作は要りません。止まっている間は発動しません。
- 乱戦中・攻城中・伏兵中は発動しません。
- 発動から0.5秒の間、範囲内の敵に1回ダメージを与えます(10+武力)。範囲は通常の槍撃と同じで、変わりません。敵がいなくても発動し、クールダウンに入ります。クールダウンは3秒です。

### 弓兵

**通常攻撃**
- 攻撃対象は、**移動方向**を基準に、射程(230)内で最も近い敵です。移動方向から60度以内の敵だけを対象にします。射程外や後方の敵は撃ちません。
- 対象がいれば、自動で射ます(間隔1.3秒、ダメージ=4+武力×0.7)。移動中も撃ちます。攻城中は撃ちません。
- 攻城中の敵に当たると、その敵の攻城ゲージを減らします。

**走射**
- 停止している間、**走射ゲージ**が貯まります(3秒で満タン)。移動中はゲージが保持されます。乱戦中は貯まりません。
- ゲージが満タンの状態で移動を始めると、そのとき攻撃している対象に**走射**が発動し、追加ダメージを与えます(通常攻撃1発の60%)。
- 走射後、ゲージは空になります。対象がいなければ、走射は発動せず、ゲージは満タンのままです。
- 走射ゲージは、カードの一覧の「走射」のバーで見られます。

### 剣豪

**斬撃ゲージ**
- 剣豪には斬撃ゲージがあり、**時間で貯まります**(開戦時は空。3.5秒で満タン)。満タンになると斬撃可能になります。
- 満タンでないと、斬撃は発動しません。
- 斬撃ゲージは、カードの一覧の「斬撃」のバーで見られます。

**斬撃**
- 満タンの状態で**カードを振る**と発動します。カードを振る操作は、カードをドラッグしながら、短い距離(約140以内)を素早く、2往復ほど動かす操作です。ダブルクリックでも発動できます。
- 自分の位置を中心とした半径80の範囲に発生します。範囲内の敵**全員**にダメージ(10+武力×1.2)を与え、弾き飛ばします(35)。特定の敵を選ぶ必要はありません。範囲外の敵には当たりません。
- 範囲内に敵がいなくても発動できます(空振りでは、敵にダメージを与えられません)。発動するとゲージは消費されます。
- 発動するとゲージが空になり、すぐ次の蓄積が始まります。
- 突撃可能な騎兵に当たると、騎兵が減速します(3秒、半分)。

### 鉄砲隊

**捕捉(ターゲティング)**
- 移動方向を基準に、射程(300)内かつ60度以内で、**最も近い敵**を射撃対象として捕捉します。
- 捕捉している敵には、鉄砲隊から敵に向かって**ターゲットライン**(赤い点線と敵を囲む輪)が表示されます。ターゲットラインは自分の画面にだけ出ます。
- いまの対象が範囲内にいる間は、対象を維持します。範囲外に出たり、移動方向が変わって角度から外れると、そのときの最も近い敵に切り替わります。

**射撃**
- 敵を捕捉している状態で、**カードを前後(縦)に揺らす**と射撃します。ダブルクリックでも射撃できます。
- 捕捉している敵だけにダメージ(10+武力×1.4)を与えます。射線上の別の敵には当たりません。
- 捕捉している敵がいないと、射撃できません。

**チャージ**
- 射撃すると、次の射撃までの**チャージ**が始まります(3秒)。チャージの進み具合は、カードの一覧の「チャージ」のバーで見られます。
- チャージが終わるまで、揺らしても射撃できません。射撃のたびにチャージはリセットされます。
- 開戦時はチャージが完了しています。

**特技「狙撃」**: 同じ敵を2秒捕捉し続けてから撃つと、ダメージが1.8倍になり、弾き飛ばします。

### 乱戦

敵部隊と接触(部隊の直径以内)すると乱戦になります。武力に応じた持続ダメージ(武力×1.4/秒)を受け、移動速度が0.3倍になります。

## 8. 特技

| 特技 | 効果 |
|---|---|
| 伏(伏兵) | 開戦時に隠れて始まる。敵に見えず、接触すると解除。知力差でダメージ |
| 柵(防柵) | 自城の前方に柵を置いて開戦。敵部隊の進路を阻む |
| 活(復活) | 復活までの時間が0.6倍 |
| 気(気合) | 受けた通常ダメージの一部を、定期的に回復 |
| 狙(狙撃) | 同じ対象を一定時間ロックして撃つと、強い射撃と弾き飛ばし |
| 昂(昂揚) | 開戦時の士気が、コストの分だけ増える |
| 先(先陣) | 開戦から20秒、武力・知力が+2 |
| 疾(疾駆) | 移動速度が1.2倍 |
| 兵(大兵) | 同時代の「兵」持ちのコスト合計に応じて、最大兵力が増える |
| 盟(同盟) | 最大士気が、コストの分だけ増える(上限15) |
| 槍(槍術) | 槍が長くなる(+8×コスト) |
| 忍 | 隠密状態になれる。敵が近づく、攻城する、ダメージを受けると解除 |
| 鬼 | 兵力が40%未満のとき、アクション・乱戦のダメージが半分 |

**表示のみで、効果は未実装**: 技・黄・覇・星・霊。

## 9. 計略・短計

- 計略は、選択中のカードの計略を `Q` で使います。使うと士気を消費します(カードごとの `mp`)。
- 通常の計略は、1回の復活につき1回だけ使えます。**短計**は、25秒のクールダウンで何度でも使えます。
- 計略は1324種ありますが、個別には実装せず、カテゴリから**汎用の効果**を適用します。

| カテゴリ | 効果 |
|---|---|
| 強化 | 自身の武力+3、速度1.1倍 |
| 全体強化 | 味方全員の武力+2 |
| 妨害 | 半径200内の敵の武力−2、速度0.8倍 |
| ダメージ | 半径170内の敵に、14+知力×2.2のダメージ |
| 回復 | 自身と半径150内の味方の兵力を、最大の25%回復 |
| 短計 | 上記の効果に加え、持続が0.6倍、クールダウン25秒 |

- 陣形・拠点・ため計略などは、強化扱いです。どれにも当たらない場合も、強化になります。
- 持続時間は、計略の `time` で決まります。知力時間は3秒+知力×0.9秒、一瞬は1.5秒、固定時間は10秒、「撤退するまで」は永続です。
- 計略を使うと、伏兵・隠密は解除されます。

## 10. 画面表示の隠し情報

サーバーは、相手の画面に出してはいけない情報を、そもそも送りません。

- 相手の目的地(`tx`/`ty`)、計略の状態、クールダウン、復活までの時間
- 城内・撤退中の敵部隊
- 伏兵・隠密で隠れている敵部隊
- 敵城エリア内にいる敵部隊

# mytaisen

英傑大戦風のブラウザ対戦ゲーム（2人・ネット対戦）。Bun 製。

- 左の**カードフィールド**でカードをドラッグして指示 → 右の**バトルフィールド**で部隊が遅れて動く
- 自城は常に画面の下側、敵城は上側（後攻側は表示を反転）
- クライアント同士は直接接続せず、操作をサーバーへ送り、サーバーが状態を計算して返す（サーバー権威）
- CPU 戦なし

## 使い方

```bash
bun install
bun run dev        # http://localhost:3000 （LAN内の相手は http://<このPCのIP>:3000 ）
```

1. デッキを編成（総コスト9以内・8枚以内・同名武将不可）
2. 片方が「部屋を作る」→ 4文字の部屋コードを相手に伝える → 相手が「参加する」
   - 「ひとりで練習」: 相手なしで開始し、自分の部隊だけで動作確認できます（相手側は動かず見えません。敵城は攻撃できます）
3. 操作: カードをドラッグ（城の外へ出すと出城、城へ戻すと帰城）/ `Q` 計略 / `Space` アクション（槍撃・斬撃・射撃）/ `1-8` カード選択

`PORT` 環境変数で待受ポートを変更できます。

## Cloudflare Workers で動かす（Durable Objects）

`wrangler.jsonc` と `src/worker/index.ts` が Workers 版です。1部屋 = 1つの Durable Object で、部屋ロジックは Bun 版と共通の `src/shared/room.ts` を使います。

```bash
bun run cf:dev       # 静的ファイルをビルドして wrangler dev（http://127.0.0.1:8787）
bun run cf:deploy    # デプロイ（Cloudflare アカウントのログインが必要: bunx wrangler login）
bun run check:worker # Worker 側の型チェック
```

無料枠の目安: 1試合(約240秒)で約31 GB秒。Durable Objects の無料枠は13,000 GB秒/日。条件は変わるので公式の料金ページで確認してください。

## コマンド

```bash
bun test               # ゲームロジック + WebSocket 結合テスト
bun check              # 型チェック
bun run build:cards    # datalist.json → data/cards.json
bun run gen:images -- --limit 40 --concurrency 3   # codex でカード画像を生成
```

## 構成

- `src/shared/game.ts` — 純粋なシミュレーション（サーバーが 20Hz で `tick`）
- `src/shared/constants.ts` — **バランス値はすべてここ**（公式値ではなく仮定義）
- `src/server.ts` — Bun.serve（WebSocket / ルーム管理）
- `src/web/` — React フロント（2面は canvas 描画）
- `scripts/gen-images.ts` — `codex exec` の画像生成でオリジナル画像を作成 → `public/cards/<番号>.jpg` と `manifest.json`。画像が無いカードは色と兵種の代替表示

## ルールの実装範囲（簡易コア）

公式プレイガイドを参考にした**簡易再現**です。数値は仮です。

- デッキ: 総コスト9以内 / 8枚以内 / 同名不可。最大士気は勢力(色)数で 12/10/8/6
- 制限時間 99 カウント（1カウント = 2.4 秒）。城ゲージが0、または時間切れで城ゲージが多い方の勝ち
- 攻城: 敵城エリアには入れず、城壁で止まって攻撃。城門は城の中央にあり、同時に攻撃できるのは1部隊だけ（城壁の3倍のダメージ）。城壁は何部隊でも攻撃可
- 兵種アクション: 騎兵の加速と突撃（初速から加速し、突撃発動速度に達すると突撃オーラが出て突撃可能。止まる・向きが大きく変わると速度を失う）、槍の迎撃・槍撃、弓の射撃・走射、剣豪の斬撃、鉄砲の射撃（相性はダメージ倍率ではなくアクション同士の関係）
- 特技: 伏・柵・活・気・狙・昂・先・疾・兵・盟・槍・忍・鬼 を実装。技・黄・覇・星・霊 は表示のみ
- 計略: 1324 種の個別実装はせず、カテゴリ（強化 / 全体強化 / 妨害 / ダメージ / 回復 / 短計）から汎用効果を適用。陣形・拠点・ため計略などは強化扱い
- 兵種アクションの入力判定（旋回・往復など）は、ボタン / Space で代替
